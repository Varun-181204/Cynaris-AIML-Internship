ChromaDB is an open-source vector database used to store and retrieve embeddings with associated metadata and documents. A collection groups related records. Each record can contain an identifier, an embedding, document text, and metadata. Similarity search retrieves records whose vectors are close to a query vector. PersistentClient stores database data on disk so it can be reused across application runs. In a RAG application, ChromaDB can serve as the persistent vector store connected to a framework such as LlamaIndex.
