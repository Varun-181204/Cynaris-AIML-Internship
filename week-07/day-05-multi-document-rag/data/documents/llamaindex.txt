LlamaIndex is a data framework for building applications powered by large language models. It connects private or domain-specific data to LLMs through data connectors, indexes, retrievers, query engines, and response synthesis. A typical workflow loads documents, transforms them into nodes, creates an index, retrieves relevant nodes, and generates a grounded response. VectorStoreIndex is a commonly used index that stores vector representations of document chunks and retrieves semantically relevant content.
