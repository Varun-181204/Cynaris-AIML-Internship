Embeddings are numerical vector representations of text. An embedding model maps text into a high-dimensional vector space in which semantically related text is expected to have similar representations. Documents are split into chunks and embedded before indexing. At query time, the question is embedded using the same compatible embedding model, and vector similarity is used to retrieve relevant chunks. Embedding quality, chunk size, overlap, and the choice of model can affect retrieval quality. Ollama can run embedding models locally, including nomic-embed-text.
